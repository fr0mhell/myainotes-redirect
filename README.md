# myainotes-redirect

Redirects the old site host `myainotes.linked-robot.com` to `https://minutify.app`, keeping the path.
GitHub Pages serves `404.html` for every unknown path, so `/privacy` lands on `https://minutify.app/privacy`.
Runbook: `website/README.md` in fr0mhell/my-ai-notes, section "Old host redirect".
